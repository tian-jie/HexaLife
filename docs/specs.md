# Virus Spreading Simulator / 病原世界

内部开发代号：HexaLife

## 1. 项目概述

在平面六边形格子上，模拟具有代际衰减特性的病毒在生命个体之间的传播。

格子表示空间，不表示人。一个格子可以有 0 名、1 名或多名生命。生命可以健康、感染、免疫。生命会自然出生和自然死亡；因病毒死亡或自然死亡后，该生命从所在格子移除，并分别计入病毒死亡统计和自然死亡统计；格子本身保留。格子上没有生命时，地图上显示为黑色。

地图是不环绕的矩形平面。生命会按短距离高频、远距离低频的规律随机移动。超出矩形的位置不是格子。

程序提供可视化界面，实时展示模拟进程，并支持开始、暂停/继续、重置和速度调节。单次模拟最多运行 10000 天，到达上限后自动暂停。

所有数值型规则都来自配置。当前数据只作为默认值。点击**开始**或**重置**时各读取一次参数并生成新世界。暂停、继续和运行期间不再读取。运行中不允许修改病毒、地图、移动和初始条件。速度滑块只改变本次运行的推进速度上限，不改变上述规则，也不写回配置。

本阶段模拟计算用单线程实现。随机数使用可播种的标准伪随机生成器，按第 10 节的顺序取用。

## 2. 格子与生命状态

生命只有三种状态：

| 状态 | 含义 |
|---|---|
| 健康 | 未感染，易感 |
| 感染 | 处于发病周期，可传播 |
| 免疫 | 感染后康复，免疫期内不易感 |

格子的地图颜色：

设该格人数 `count = 健康 + 免疫 + 感染`，感染占比 `ratio = 感染 / count`。

| 条件 | 颜色 |
|---|---|
| `count = 0` | 黑色 |
| `count > 0` 且没有感染者 | 绿色。健康者和免疫者同色 |
| 有感染者 | 色相按 `ratio` 从黄色过渡到红色。`ratio` 越接近 0 越黄，越接近 1 越红 |

明暗按人数的对数变化，使用该格总人数，不按感染人数单独计算：

\[
light = \frac{\ln(1 + count)}{\ln(1 + C_{bright})}
\]

`light` 限制在 0 到 1。`C_{bright}` 默认为 64：1 人较暗，64 人及以上达到最亮。没有感染者时，绿色使用这个明暗；有感染者时，黄到红的颜色使用这个明暗。

色相使用 HSV：没有感染者时色相为 120°（绿）；有感染者时色相为 \(60° \times (1 - ratio)\)，即 60° 为黄、0° 为红。饱和度为 1。`light` 用作 HSV 的明度。

免疫和健康在地图上同为绿色。悬停或点击格子时仍分别显示健康、感染、免疫人数。

补充规则：

- 死亡不在地图上单独显示。死亡者立即离开格子；该格若还有其他生命，继续按剩余生命着色。
- 累计病毒死亡人数、每日新增病毒死亡人数、分代累计病毒死亡人数单独统计。累计自然死亡人数、每日新增自然死亡人数也单独统计。
- 免疫持续可配置的免疫期，默认 180 天；到期后变回健康，可以再次被感染。
- 再次感染时，代际只由新父代决定，不继承上一次感染的代际。
- 感染代际分为 0 代、1 代、2 代、3+ 代。新感染者代际为父代代际 +1；结果大于等于 3 时记为 3+。
- 初始感染者是 0 代。

## 3. 地图与生命分布

### 3.1 平面格子

- 地图是平面六边形矩形，宽 `width` 格、高 `height` 格。默认都是 10000，共 1 亿格。
- 坐标为 `(q, r)`。`q` 的范围是 0 到 `width - 1`，`r` 的范围是 0 到 `height - 1`。
- 格子编号 `index = r * width + q`。指定位置时使用格子编号或坐标。
- 邻居使用轴向六边形的 6 个方向：`(q+1,r)`、`(q-1,r)`、`(q,r+1)`、`(q,r-1)`、`(q+1,r-1)`、`(q-1,r+1)`。
- 坐标超出矩形的位置不存在。边缘格子少于 6 个邻居。地图不环绕。
- 两格距离为六边形距离：

\[
dist = \frac{|q_1-q_2| + |r_1-r_2| + |(q_1+r_1)-(q_2+r_2)|}{2}
\]

- 移动候选落在矩形外时，该候选不存在。某个距离上没有矩形内的格子时，这个距离不参与抽样。允许范围内没有任何合法格子时，生命留在原地。

### 3.2 初始人数

初始人数 `initial_population` 默认 100000000，可配置。生成结束时的生命数正好等于该值。一个格子可以是 0 人，也可以是多人。

格子的权重：

\[
\lambda(C) = \lambda_{bg} + \sum_k A_k \exp\left(-\frac{dist(C, c_k)^2}{2\sigma_k^2}\right)
\]

- \(\lambda_{bg}\)：背景权重，默认 0.2。它不是人数。
- \(c_k\)：第 \(k\) 个人口中心的格子编号。
- \(A_k\)：该中心的峰值权重，默认 4。
- \(\sigma_k\)：影响半径，单位为格，默认 20。
- 与中心的距离大于 `truncation * σ` 时，该中心对这个格子的贡献为 0。`truncation` 默认 4。
- 默认放置 6 个人口中心，具体编号写入配置。
- 格子 \(C\) 的期望人数是 `initial_population * λ(C) / Σλ`。`Σλ` 等于背景总权重加上各中心在截断窗口内的权重和。背景总权重是 \(\lambda_{bg} \times width \times height\)。

放置方法：

1. 计算背景总权重，以及每个中心在截断窗口内、且落在矩形中的权重和。
2. 按生命编号从 0 到 `initial_population - 1` 依次抽取格子。
3. 每次先按上述权重和选择来源：整个背景，或某一个中心。
4. 来源是背景时，在全部格子中均匀抽取。
5. 来源是中心时，只在该中心的截断窗口内按 \(\exp(-dist^2 / (2\sigma^2))\) 抽取；窗口里超出矩形的位置权重为 0。
6. 同一格子可以被多次抽中。

每名生命的常住点是他生成时所在的格子。生命编号从 0 起递增分配，运行期间不回收、不重排。初始人口是第 0 天的人口。之后人口由出生和自然死亡动态变化。

全部权重为 0，或 `initial_population < 1`：拒绝开始或重置。

### 3.3 初始感染

- 初始感染人数默认 1，可配置。
- 放置方式可配置：在全部生命中均匀随机抽取，或指定格子编号。
- 指定格子时，在该格已有生命中均匀随机抽取一人。
- 初始感染者视为在第 0 天已经被感染。
- 初始感染人数大于总人口，或指定格子上没有生命：拒绝开始或重置，并指出配置项。

相同配置和随机种子下，地图、初始人口和初始感染可复现。

## 4. 病毒参数

### 4.1 发病周期与天数

被感染后进入发病周期，默认 7 天，可配置，记为 \(D\)。\(D\) 为正整数。

设某生命在第 \(T\) 天的传播阶段被感染，或初始感染者的 \(T = 0\)：

- 传染日是第 \(T+1, T+2, \ldots, T+D\) 天，共 \(D\) 天。
- 每个传染日，该生命先移动（若允许），再传播，再接受一次死亡判定。
- \(D\) 次死亡判定都未死亡，则在第 \(T+D\) 天的死亡/康复阶段转为免疫。
- 免疫日是第 \(T+D+1\) 天到第 \(T+D+N\) 天，共 \(N\) 天。\(N\) 默认 180。
- 第 \(T+D+N+1\) 天开始时变回健康。这一天先变健康，当天可以被感染。

例：\(D = 7\)，\(N = 180\)，第 10 天被感染。

- 第 10 天不再移动、不传播、不进入死亡判定。
- 第 11 天到第 17 天为传染日。
- 第 17 天仍存活，则当天结束患病并转为免疫。
- 第 18 天到第 197 天为免疫日。
- 第 198 天开始时变回健康。

感染当天不传播，是因为传播阶段里新感染者还不是当天的传染源。感染当天不移动，是因为移动发生在传播之前。死亡判定只对当天开始时已经处于传染日的生命执行。

### 4.2 接触与每日感染概率

传染日当天，一名感染者的接触范围是：自己所在格子，以及该格的全部相邻格子。

总感染率 \(P_g\) 的含义是：感染者活满 \(D\) 个传染日，且这 \(D\) 天里另一名健康者每天都在他的接触范围内时，该健康者被这名感染者感染的概率。

各代默认值：

| 代际 | 总感染率 \(P_g\) | 折算每日概率（D=7）|
|---|---:|---:|
| 0 代 | 70% | 16.0% /天 |
| 1 代 | 55% | 10.8% /天 |
| 2 代 | 45% | 7.2% /天 |
| 3+ 代 | 25% | 4.0% /天 |

各代均可配置，取值范围为 0 到 1。

每日感染概率把总感染率折成 \(D\) 次独立判定，使活满周期时的累计概率正好等于 \(P_g\)：

\[
p_g = 1 - (1 - P_g)^{1/D}
\]

\(P_g = 1\) 时，\(p_g = 1\)：这名感染者会在第一个传染日感染当时接触范围内的每一名健康者。默认总感染率低于 100%。要减弱传播时，调低各代 \(P_g\)。

感染者在第 \(k\) 个传染日死亡时，他只完成了 \(k\) 次传播。\(k < D\) 时，某个健康者被他感染的概率低于 \(P_g\)。

### 4.3 同一天多名感染者

对每名健康者，用当天移动结束后的位置，找出接触范围内的全部感染者。只包括当天处于传染日的感染者。

每名感染者 \(i\) 独立判定是否命中该健康者，命中概率为 \(p_{g(i)}\)。

- 无人命中：当天不被感染。
- 有人命中：当天被感染。父代在命中者中随机选择，每日感染概率越高，被选中的概率越高。

命中者按生命编号升序记为 \(i_1, \ldots, i_m\)，权重为各自的 \(p\)。父代概率：

\[
\Pr(\text{父代}=i_k) = \frac{p_{g(i_k)}}{\sum_{j=1}^{m} p_{g(i_j)}}
\]

抽样方法固定为：取 \(U \in [0,1)\)，按升序累加权重，选中第一个使累加和大于 \(U \times \sum p\) 的命中者。代际由该父代计算。

因此多名感染者同时接触一人时，感染概率高于其中任何单独一人；父代倾向于每日感染概率更高的命中者。只有一名命中者时，父代就是他。

### 4.4 致死率

总致死率 \(L_g\) 是感染者在 \(D\) 个传染日的死亡判定中至少死亡一次的概率。

| 代际 | 总致死率 \(L_g\) |
|---|---:|
| 0 代 | 40% |
| 1 代 | 30% |
| 2 代 | 20% |
| 3+ 代 | 5% |

各代均可配置，取值范围为 0 到 1。

每个传染日独立判定一次死亡：

\[
\delta_g = 1 - (1 - L_g)^{1/D}
\]

活满 \(D\) 天的概率是 \((1-\delta_g)^D = 1-L_g\)。因此只要该生命走完发病周期，累计死亡概率就等于配置的 \(L_g\)，与他所在位置无关。

当天先传播，再做死亡判定。死亡当天的传播已经发生。死亡后不再传播，也不转为免疫。

\(D\) 次判定都未死亡的生命，在最后一个传染日的死亡/康复阶段转为免疫。发病期间不会提前康复。

### 4.5 免疫

- 免疫期默认 180 天，可配置，记为 \(N\)。\(N\) 为非负整数。
- 免疫期内不能被感染，也不传播。
- 免疫状态属于生命，随生命移动。
- 免疫期满后，在下一天开始时变回健康。
- \(N = 0\) 时，转为免疫的下一天开始时立即变回健康。

### 4.6 感染期内移动

- 全局参数：感染者在传染日是否允许移动，默认 `true`。
- 为 `true` 时，传染日按移动模型移动，并在移动后的位置传播。
- 为 `false` 时，传染日留在原地。
- 健康者和免疫者不受该参数影响。
- 被感染的当天还不是传染日，当天本来就不会移动。

### 4.7 人口自然出生与自然死亡

人口在模拟过程中会自然出生和自然死亡，与病毒无关。

**自然死亡**：

- 每名存活生命每天有一个自然死亡概率，记为 `natural_death_rate_per_day`，可配置，取值范围 0 到 1。
- 自然死亡判定在每天传播之后、病毒死亡判定之前执行。
- 自然死亡的生命不参与当天的病毒死亡判定，也不转为免疫。
- 自然死亡的生命从格子移除，计入自然死亡统计，不计入病毒死亡统计，也不计入分代累计病毒死亡。
- 自然死亡与感染状态无关：健康、感染、免疫者都可能自然死亡。

**出生**：

- 每名存活生命每天有一个生育概率，记为 `birth_rate_per_day`，可配置，取值范围 0 到 1。
- 出生判定在每天死亡与康复阶段之后执行。
- 生育者在当前所在格子新增一名健康生命。新生儿的常住点为该格子。
- 新生儿获得新的生命编号，编号从初始人口编号之后继续递增。死亡的生命编号不回收。
- 新生儿是健康状态，没有免疫，没有感染代际。
- 新生儿从下一天开始参与移动、传播和被感染。出生当天不移动、不传播、不被感染。
- 健康、感染、免疫者都可以生育。新生儿不继承父母的感染或免疫状态。

**与病毒参数的关系**：

- 自然死亡率和出生率独立于病毒参数。
- 在自然死亡率为 0 时，病毒致死率按第 4.4 节完全生效。
- 在病毒致死率为 0 时，自然死亡率按配置完全生效。
- 自然死亡先于病毒死亡判定。因此病毒致死率是在"未自然死亡"条件下的概率。实际病毒死亡人数会略低于按总人口和 \(L_g\) 计算的值，因为部分感染者先自然死亡了。

**人口动态**：

- 没有病毒时，人口长期趋势由出生率和自然死亡率共同决定。
- 出生率大于自然死亡率时人口增长，反之减少。
- 默认值下人口缓慢增长。

## 5. 每日运行规则

模拟从第 0 天的初始世界开始。第 0 天不执行下面的循环。循环从第 1 天执行到第 `maxDays` 天，默认 10000。完成上限那天的统计后自动暂停，不再前进。

每一天按以下顺序运行，上一步全部完成后再进入下一步：

1. **免疫到期**：免疫日已经结束的生命变回健康。
2. **移动**：允许移动的活生命按第 6 节尝试移动，每人最多一次。
3. **传播**：按第 4.2、4.3 节，由本步开始时已经处于传染日的感染者传播。本步新感染的生命，当天不传播。
4. **死亡与康复**：
   - 对每名存活生命，先按 `natural_death_rate_per_day` 判定自然死亡。自然死亡者从格子移除，计入当日自然死亡数和累计自然死亡数，不再进行后续判定。
   - 对未自然死亡、且本步开始时已经处于传染日的感染者，按第 4.4 节判定病毒死亡。病毒死亡者从格子移除，计入当日病毒死亡数、累计病毒死亡数和分代累计病毒死亡数。
   - 对未自然死亡、未病毒死亡、且当天是最后一个传染日的感染者，转为免疫。
5. **出生**：
   - 对每名存活生命（健康、感染、免疫），按生命编号升序，以 `birth_rate_per_day` 判定是否生育。
   - 生育者在当前所在格子新增一名健康生命。新生儿获得新编号，常住点为该格子。
   - 新生儿从下一天开始参与移动、传播和被感染。出生当天不移动、不传播、不被感染。
6. **统计**：记录当天结果。界面按第 7 节刷新。

移动不改变健康、感染、免疫。死亡者在第 4 步从格子中移除。

## 6. 生命随机移动模型

### 6.1 目标

- 短距离、高频移动为主。
- 距离越远，发生概率越低。
- 较低概率发生中距离移动，更低概率发生远距离移动。
- 移动不改变生命状态。
- 常住点附近的格子更容易成为短距离和中距离移动的目的地。

### 6.2 基本规则

- 健康、感染、免疫都可以移动。感染者是否能在传染日移动，由第 4.6 节的参数决定。
- 每个生命每天最多移动一次。
- 目的地可以是任何格子，包括已经有其他生命的格子。
- 多人可以进入同一格子。移动不会因为目的地有人而失败。
- 距离按第 3.1 节的图距离计算。

### 6.3 移动类型：互斥，短距离优先

每个允许移动的生命，每天使用一个 \(U \in [0,1)\) 抽取至多一种移动。三种概率都是绝对日概率，按短距离到长距离占用随机数区间：

设 \(p_c\)、\(p_v\)、\(p_t\) 分别为通勤、探亲、旅游的日概率。

| 区间 | 结果 |
|---|---|
| \(0 \le U < p_c\) | 日常通勤 |
| \(p_c \le U < p_c + p_v\) | 探亲 |
| \(p_c + p_v \le U < p_c + p_v + p_t\) | 旅游 |
| 其余 | 留在原地 |

默认值：

| 类型 | 日概率 | 距离范围（格） |
|---|---:|---|
| 日常通勤 | \(p_c = 0.30\) | 1～5 |
| 探亲 | \(p_v = 0.05 / 7\) | 6～50 |
| 旅游 | \(p_t = 0.01 / 365\) | 51～500 |

距离范围互不重叠。\(p_c + p_v + p_t\) 必须小于等于 1，否则拒绝开始或重置。

### 6.4 距离

选中类型后，设距离范围为 \([d_{min}, d_{max}]\)，当前位置为 \(X\)。只考虑该范围内、并且从 \(X\) 确实存在格子的距离 \(d\)。若整个范围内都没有其他格子，留在原地。

距离权重：

\[
w(d) = 2^{-(d - d_{min}) / \tau}
\]

\[
\Pr(d) = \frac{w(d)}{\sum_k w(k)}
\]

\(\tau\) 是该类型的距离衰减尺度，默认：

| 类型 | \(\tau\) |
|---|---:|
| 日常通勤 | 1 |
| 探亲 | 10 |
| 旅游 | 80 |

通勤每远 1 格权重减半。探亲和旅游衰减较慢，使配置的远距离仍然可能被抽到。矩形外的格子不参与抽样。某个距离在矩形内没有格子时，该距离的权重为 0。

### 6.5 目的地与常住点

抽出距离 \(d\) 后，在与 \(X\) 图距离恰好为 \(d\) 的格子中选择目的地 \(C\)。常住点为 \(H\)。

\[
w(C) = 2^{-\beta \cdot dist(C, H)}
\]

\[
\Pr(C) = \frac{w(C)}{\sum_B w(B)}
\]

\(\beta\) 默认：

| 类型 | \(\beta\) |
|---|---:|
| 日常通勤 | 1 |
| 探亲 | 0.1 |
| 旅游 | 0 |

通勤时，离常住点每远 1 格，目的地权重减半。生命已经离开常住点时，会优先走向更接近常住点的格子。生命正站在常住点上时，同一距离环上的格子权重相同。旅游不偏向常住点。

同一权重下按格子编号升序做累加抽样，方法与第 4.3 节的父代抽样相同。

常住点在生命生成时确定，之后不改变。新生儿的常住点为出生时所在格子。

## 7. 界面展示与运行控制

### 7.1 目标

界面展示病毒在平面地图上的传播、生命聚集和死亡，并让用户控制模拟运行。健康与免疫在地图上同色，两类人数在悬停信息和统计面板中分开显示。

产品名称：**Virus Spreading Simulator**  
中文名称：**病原世界**  
界面标题：`Virus Spreading Simulator — 病原世界`

内部代号 HexaLife 不作为界面标题。

### 7.2 界面组成

1. **地图主视图**
   - 按第 2 节的颜色展示格子。
   - 提供图例，说明黑色、绿色、由黄到红，以及明暗对应人数。
   - 地图可平移、可缩放。
   - 悬停或点击格子时，显示该格健康、感染、免疫人数。
   - 默认地图不逐格绘制。画面只显示当前视野；缩小后按块汇总人数和感染占比，再套用第 2 节的颜色。统计数字来自完整模拟，不来自画面抽样。
2. **运行控制区**
   - **开始**：仅在未开始时可用。
   - **暂停 / 继续**：运行中可暂停；暂停后可继续。
   - **重置**：读取配置，丢弃本轮世界，生成新世界并开始运行。
   - 按钮随状态启用或禁用。
3. **速度控制**
   - 调节本次运行每秒推进天数的上限。
   - 使用滑块或下拉选择。
   - 速度范围可配置，默认 1～60 天/秒，并提供“最快”档。
   - 一天的计算时间短于上限间隔时，按上限等待。一天的计算时间更长时，算完即进入下一天，不再额外等待。
   - “最快”表示不插入等待。界面仍按刷新频率更新。
   - 开始或重置时的初始速度来自当次读入的配置。运行中和暂停时都可以调速度，立即生效。
   - 调速度不重新读取配置，也不改变病毒、地图和移动参数。
4. **状态面板**
   - 当前天数 \(T\)。
   - 当前总活生命数。
   - 健康、感染、免疫人数。
   - 累计病毒死亡数、当日新增病毒死亡数、分代累计病毒死亡数。
   - 累计自然死亡数、当日新增自然死亡数。
   - 累计出生数、当日新增出生数。
   - 当日新增感染数、当日新增免疫数。
   - 各代际当前感染人数：0、1、2、3+。
   - 到达最大天数时显示已停止。

### 7.3 运行控制语义

- **未开始**：没有正在使用的世界。开始可用。暂停、继续不可用。
- **开始**：读取一次配置并校验。校验失败则保持未开始，并指出配置项。校验成功则生成 \(T = 0\) 的世界，然后按速度从第 1 天推进。
- **暂停**：停止推进，界面保持最后状态。不读取配置。
- **继续**：从暂停处接着运行。不读取配置。已到达最大天数时不可用。
- **重置**：再读取一次配置并校验。校验失败则保持当前世界和当前暂停或运行状态，并指出配置项。校验成功则丢弃当前世界，用新参数生成 \(T = 0\) 的世界，并开始推进。
- 到达 `maxDays` 后自动暂停。继续不再前进。
- 开始和重置成功之后，暂停与继续使用该次读入的参数。

速度和刷新不改变随机结果。同一配置、同一随机种子，无论速度如何，每天的统计都相同。

### 7.4 界面刷新

- 运行中按可配置的刷新频率更新地图和统计。
- 模拟按天完整计算；刷新可以跳过中间画面，不能跳过模拟日。
- 暂停时界面保持最后状态。
- 地图可以降采样，统计必须按真实模拟结果表示。

## 10. 随机数与复现

本阶段模拟计算只使用一条随机流，跑在单个模拟线程上。随机数使用语言标准库中可播种的伪随机生成器，由配置里的随机种子初始化。不使用操作系统真随机。

同一种子、同一配置、同一处理顺序下，每日统计必须相同。暂停、继续、速度和界面刷新不消耗这条随机流。

处理顺序固定为：

1. 生成人口：按生命编号从 0 到 `initial_population - 1` 依次抽取所在格子。
2. 放置初始感染：按感染序号依次抽取生命。
3. 每一天按第 5 节的阶段顺序执行。同一阶段内按生命编号升序。
4. 传播阶段中，按目标生命编号升序处理健康者。对每个目标，按感染者编号升序做命中判定；出现命中后再抽取父代。

开始和重置各自用当次读入的种子重新初始化随机流。

## 11. 验收标准

1. 默认生成 10000×10000 的平面六边形矩形。内部格子有 6 个邻居，边缘格子少于 6 个，矩形外没有格子，也不环绕。
2. 初始生命数正好等于配置的 `initial_population`。人口中心附近更密，同一格子可以有 0 名或多名生命。
3. 能放置 1 名 0 代感染者，并从第 1 天起按传染日传播。
4. 只有一名感染者、目标始终在接触范围内且感染者活满周期时，感染概率等于该代 \(P_g\)。
5. 在自然死亡率为 0 时，每名感染者走完发病周期时，病毒死亡概率等于该代 \(L_g\)。
6. 同一天多名感染者命中同一健康者时，按第 4.3 节选择父代，代际计算正确。
7. 发病天数和免疫天数符合第 4.1 节的例子。
8. 死亡者从格子移除。格子无人时显示黑色；仍有其他生命时按剩余人数着色。分代累计病毒死亡数正确。
9. 三种移动每天最多抽中一种，区间顺序为通勤、探亲、旅游。
10. 在可选距离中，更近的距离权重符合第 6.4 节；通勤目的地偏向常住点。
11. 目的地已有生命时，移动仍然成功。
12. 界面展示平面地图、图例、天数、各状态人数、病毒死亡、自然死亡、出生、分代病毒死亡和各代感染人数。无人的格子为黑色，无感染者为绿色，感染占比决定黄到红，明暗按总人数的对数变化。
13. 悬停或点击格子能看到该格健康、感染、免疫人数。
14. 开始、暂停/继续、重置的可用状态符合第 7.3 节。开始和重置各读取一次参数；暂停、继续和运行中不读取。重置校验失败时，当前世界保持不变。
15. 运行中调整速度立即生效。速度只改变等待上限，不改变同一天的模拟结果。计算超过上限时不再额外等待。
16. 完成第 10000 天后自动暂停，继续不再前进。
17. 重置在校验成功后用新读入的参数生成世界并开始运行。校验失败时不丢弃当前世界。
18. 固定随机种子时，重复开始得到相同的每日统计。速度和刷新频率不改变该统计。
19. 非法配置被拒绝，并指出配置项。开始失败时保持未开始；重置失败时保持当前世界。
20. 默认规模下界面可平移和缩放。画面可以按块汇总，统计仍然按全图真实结果计算。
21. 自然死亡率和出生率符合配置。自然死亡先于病毒死亡判定，自然死亡者不计入病毒死亡和分代累计病毒死亡。自然死亡者从格子移除；格子无人时为黑色，仍有其他生命时按剩余人数着色。
22. 新生儿是健康状态，从下一天开始参与移动、传播和被感染；获得新编号，编号不回收；常住点为出生时所在格子。
23. 无病毒时，人口长期趋势由出生率和自然死亡率共同决定；出生率大于自然死亡率时人口增长，反之减少。
